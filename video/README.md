# Demo video

`demo.mp4` is a real screen recording of Spliteline running on Arc mainnet: creating a split, paying into it with `payNative`, releasing both recipients' shares, a look at the source in Arc Studio, and the proof page showing the full transaction history. Every click is real, every transaction is signed live, nothing is staged.
